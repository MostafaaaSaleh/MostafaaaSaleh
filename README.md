## 👋 About Me

I'm a **Senior Full Stack .NET Developer and Senior Business Analyst** based in **Sharjah, UAE**. For over 13 years I've designed, built and delivered enterprise web platforms for **UAE government and enterprise organizations**: ERP, e-commerce, POS, booking and licensing systems.

What sets me apart is that I own the whole journey: I sit with stakeholders to gather requirements and model the process, then design the architecture, write the code, test it and take it to production.

- 🏛️ Currently **Senior Software Developer / Senior BA at Sharjah Museum Authority** (since 2020)
- 🧩 Building on **.NET Core, C#, Angular, Blazor and SQL Server**
- 📐 Writing **BRDs, SRS/FRDs, BPMN models, user stories and UAT plans**
- 👨‍🏫 Mentoring developers through code reviews and pair programming
- 🌍 Arabic (native) · English (professional)
